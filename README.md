# allai

一个从零开始的个人 AI 工作台：把模糊想法整理成可复用的提示词和任务。

## 当前功能

- 学习、写作、计划、代码排错提示词模板
- 本地保存、搜索、载入和删除任务
- 复制提示词、导出 JSON 备份
- 响应式中文界面，不需要账号、API 密钥或第三方依赖

任务保存在当前浏览器的 localStorage 中，不会上传到服务器。清除浏览器数据会删除任务，建议定期导出。当前版本不调用模型，导出文件暂时没有导入界面。

## 运行

需要 Python 3。在仓库目录执行：

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

在本地开发机器的浏览器中打开服务器地址。云环境可用内部 HTTP 请求验证服务；这里不提供云网页预览。

## GitHub Pages

仓库包含 GitHub Actions 自动部署工作流。在 GitHub 仓库的 **Settings → Pages → Build and deployment → Source** 中选择 **GitHub Actions**。推送到 `main` 或手动运行 **Deploy GitHub Pages** 工作流后，成功部署的地址为：

https://fyfq.github.io/allai/

首次启用 Pages 后，如果先前的部署失败，请到 Actions 页面重新运行工作流。页面使用相对资源路径，可部署在 `/allai/` 下。GitHub Pages 使用 HTTPS，支持复制提示词；本地开发地址与线上地址的浏览器任务库相互独立。

## 后续方向

先让任务整理和复用足够好用，再加入备份导入、任务结果记录，最后考虑通过后端接入模型。未来的模型密钥应由服务端安全管理，不能写进前端或提交到仓库。

## 验证

```sh
node --check app.js
```

浏览器中检查模板填充、保存任务、刷新后保留、搜索、载入、删除和导出。静态服务器仅用于开发。
